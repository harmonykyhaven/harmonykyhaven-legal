Política de Privacidade

Última atualização: 13 de setembro de 2026

Esta Política de Privacidade descreve como o harmonykyhaven ("o Aplicativo") coleta, usa e protege as informações necessárias para seu funcionamento.

1. Informações coletadas

O Aplicativo coleta e processa apenas os dados necessários para automatizar a publicação de vídeos na conta do TikTok autorizada pelo usuário, incluindo:

  • Tokens de acesso e atualização (access token / refresh token) fornecidos pela API OAuth da TikTok;
  • Informações básicas da conta TikTok conectada, necessárias para a publicação (como identificador da conta);
  • O conteúdo dos vídeos e legendas fornecidos pelo próprio usuário para publicação.

2. Como as informações são usadas

Os dados coletados são usados exclusivamente para autenticar a conexão com a API da TikTok e executar a publicação automatizada de vídeos solicitada pelo usuário. Nenhuma informação é usada para outros fins.

3. Compartilhamento de dados

O Aplicativo não vende, aluga ou compartilha dados pessoais com terceiros. Os dados trafegam apenas entre o Aplicativo e os servidores oficiais da TikTok, necessários para o funcionamento da automação.

4. Armazenamento e segurança

Tokens de acesso são armazenados de forma segura e usados apenas durante a execução das automações. O usuário pode revogar o acesso do Aplicativo à sua conta TikTok a qualquer momento, diretamente nas configurações de aplicativos conectados do TikTok.

5. Retenção de dados

Os dados são mantidos apenas enquanto a automação estiver em uso. Caso o usuário revogue o acesso ou solicite a exclusão, os tokens e dados associados são removidos.

6. Direitos do usuário

O usuário pode, a qualquer momento, solicitar a exclusão de seus dados ou revogar o acesso do Aplicativo à sua conta TikTok, entrando em contato pelo e-mail abaixo ou diretamente pelas configurações de privacidade do TikTok.

7. Alterações nesta política

Esta Política de Privacidade pode ser atualizada periodicamente. A versão mais recente estará sempre disponível nesta mesma página.
